# enjigirling

База данных по профессиям инженеров: статистика, обучение, зарплаты, карьерный рост.

Статический каталог инженерных профессий с модальными карточками, зарплатами по
федеральным округам, карьерным ростом, типичным днём, плюсами и минусами,
интервью, а также календарём инженерных праздников и разделом ресурсов сообщества.

## Разделы сайта

- **Профессии** — каталог инженерных специальностей (46 профессий, 28 категорий)
  с фильтрацией, подробными карточками и интервью.
- **Календарь праздников** — профессиональные и инженерные праздники по месяцам
  с фильтрацией по профессиям.
- **Ресурсы сообщества** — журналы и форумы для инженеров.

## Структура проекта

- `data.js` — данные о профессиях
- `script.js` — логика каталога профессий
- `holiday-map.js` — связь профессий с их праздниками
- `calendar-data.js` — данные о праздниках
- `calendar.js` — логика календаря
- `resources-data.js` — данные о ресурсах сообщества
- `resources.js` — логика раздела ресурсов
- `style.css` — стили сайта
- `index.html`, `calendar.html`, `resources.html` — страницы
